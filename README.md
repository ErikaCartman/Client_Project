# UMSI Engaged Learning Office — Client Project (SI 539)

Deliverable #3 builds on the mobile-first site with tablet/desktop `min-width` breakpoints, a custom `404.html`, dynamic copyright year, and a sticky stage rail + on-this-page TOC.

## Pages

- `index.html` — Home
- `preparing.html` — Preparing for Your Experience
- `starting.html` — Starting Your Experience
- `during.html` — During Your Experience
- `404.html` — Custom GitHub Pages 404

## Styles / scripts

- `css/html5reset.css` + `css/style.css` (mobile default; `@media (min-width: 768px)` and `1100px`)
- `js/main.js` — footer year + TOC scroll-spy

## Local preview

Open any HTML file in a browser, or serve the folder:

```bash
npx --yes serve .
```

Widen the viewport past 768px and 1100px to see tablet/desktop layouts.
